# 小学生算术翻翻卡 🎒 Math Flashcards for Kids

专为小学生设计的趣味 3D 悬浮算术翻翻卡网页应用。正面是算术题，背面是详细答案解析与巧算思路，支持触屏滑动、鼠标拖拽与点按翻牌。

---

## 🌟 核心特色与功能

### 1. 悬浮 3D 卡片与物理翻转体验
- **真实悬浮动效**：卡片在空中轻盈起伏，底部带有呼吸式投影，极具质感。
- **滑动与点按双交互**：
  - **点击/点按**：即刻流畅翻面；
  - **滑动/拖拽**：支持手指左右/上下划动或鼠标拖拽，卡片实时跟随手势呈现真实 3D 偏转，放手后平滑惯性翻转归位。
- **正反面设计**：
  - **正面（题目面）**：大字清晰排版、算式题型徽章、数珠/点阵辅助数数、真人中文语音题目朗读（🔊 点击小喇叭发音）。
  - **背面（答案解析面）**：醒目绿色大字答案、**凑十法/破十法/口诀巧算思路**分解、自评互动（`⭐ 我做对了！` / `🤔 再练练`）。

### 2. 覆盖小学 1 ~ 4 年级课标题库与自定义范围
- 🌟 **一年级**：10以内加减法、20以内进位加法（凑十法）、20以内退位减法（破十法）、数珠点阵图示；
- 🌟 **二年级**：100以内笔算加减法（相同数位对齐、满十进一与退位借一）、九九表内乘法口诀；
- 🌟 **三年级**：表内除法、简单有余数除法、千以内笔算加减、带小括号的两步混合运算；
- 🌟 **四年级**：运算律简便巧算（乘法分配律与拆数）、四则混合运算顺序；
- ⚙️ **自定义出题**：自由勾选 ➕ 加法、➖ 减法、✖️ 乘法、➗ 除法，并可滑动滑块设定最大计算数值范围（10 ~ 500）。

### 3. 伴学与正向激励机制
- **彩色礼花彩带（Confetti）**：点击「我做对了！」即刻绽放五彩礼花与星星。
- **战绩与连对勋章**：
  - 统计已练习题数、正确率百分比；
  - 连对激励体系：🌱 算术小苗 → 🌟 连胜达人 → 🏆 算术小天才 → 👑 算术王者！
- **内置纯原生音效（Web Audio API）**：
  - 翻牌轻柔风琴声、答对快乐和弦、答错温和弹簧声（右上角 🔔 按钮可一键静音）。
- **侧边数学草稿纸（Scratchpad）**：
  - 点击右上角「✏️ 草稿纸」即可滑出演算绘图板，支持手指/鼠标写字列竖式、多色画笔、橡皮擦与一键清空。

### 4. 键盘快捷键（桌面端）
- `空格 Space`：翻转卡片（正反面切换）
- `→` 或 `N`：下一题
- `←` 或 `P`：上一题

---

## 🚀 打开方式

该项目为**纯前端零依赖单页面应用**，无需安装任何额外包：

1. **直接双击打开**：
   直接用任意浏览器（Chrome, Safari, Edge, Firefox 等）双击 `math-flashcards/index.html` 即可运行。
2. **手机/平板（iPad）局域网体验**：
   在终端运行：
   ```bash
   cd math-flashcards && python3 -m http.server 8080
   ```
   用手机或 iPad 浏览器扫描或访问局域网 IP:8080 即可在触屏上享受丝滑的滑动翻牌体验。
